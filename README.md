# principado

V3 do site institucional da **Principado Produções**, estruturada como landing page premium e orientada à conversão para produção de eventos.

## V3

- identidade editorial premium em preto, off-white e champagne;
- hero com console visual de produção 360º;
- blueprint de estratégia → criativo → técnica → operação;
- páginas e conteúdo sem cases, números ou clientes inventados;
- briefing comercial integrado ao WhatsApp;
- mobile-first, acessibilidade e `prefers-reduced-motion`;
- SEO técnico com canonical, Open Graph e JSON-LD;
- compatível com GitHub Pages sem build step.
